# OPTIONAL report-figure stack — the `reports-figures` module in
# modules/manifest.json (type: python-package, tier: optional).
#
# ~199 MB. Install ONLY if you want the lesion-network-mapping panel's own

# nilearn move out of the base install.
#
# The LNM figures degrade with an actionable message when it is absent
# (lnm_backend._plotting).
#
#   pip install -r backend/requirements-reports.txt
#
# The standard installer's module store installs it with one click instead, from
# the files pinned in data/modules/manifest.json. After changing this file, re-pin:
#   py -3.11 tools/scripts/pin_python_modules.py

# scikit-learn is deliberately NOT pinned here: it is a hard dependency of
# nilearn and arrives with it. It was never pinned in requirements-frozen.txt
